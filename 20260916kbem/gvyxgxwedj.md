# 【喜讯】深圳市妇幼保健院新生儿科护理品管圈获得广东省首届医院品管圈大赛二等奖

> 更新时间：2026-09-16 (UTC+8)

8月3日至5日，由中国医院品质管理联盟、广东省卫生健康委员会指导，广东省医院协会、南方医院主办的**《第三届全国医院品管圈及多维管理工具应用高峰论坛暨广东省首届医院品管圈大赛》**在广州成功举办。来自全省80家医院的158个圈参加了角逐，深圳市妇幼保健院护理部推荐的新生儿科护理品管圈-圆圆圈，参加了比赛并获得三级医院护理组二等奖。

本次大赛为广东省首届医院品管圈大赛，分为三级医院护理组、专科组等组别。我院被列入三级医院护理组， 与来自省内各市知名医院且在全国品管圈大赛中有丰富经验的圈进行PK。最终深圳市妇幼保健院护理品管圈以科学严谨的设计，及汇报代表陈丽莲护士长、NICU护士罗丽清晰流利的表达及丰富的专业知识赢得了在场专家的一致好评，并在强手如云的三级医院护理组中崭露头角。
