# 以质为基 以安为本 赋能医院高质量发展-院医院质量与安全管理委员会会议顺利召开

> 更新时间：2026-09-16 (UTC+8)

**医院质量与安全管理委员会会议**

**以质为基 以安为本**

**会议前言**

SUMMARY REPORT

2026年1月23日，徐州市妇幼保健院召开医院质量与安全管理委员会会议。会议全面总结2025年度医院质量安全管理工作成效，深入剖析当前存在的薄弱环节，系统部署2026年重点改进任务。医院质量与安全管理委员会全体成员、各专业委员会主任委员及相关职能科室负责人均参会。

医疗保健质量与安全、护理质量与安全、医院感染管理、药事管理、病案管理、医疗保险管理、全面预算管理、辖区妇幼保健质量管理、运营管理等24个专业委员会负责人依次作专项工作汇报。各负责人立足核心职责，结合年度工作情况，用详实数据和典型案例，全面梳理了2025年在制度建设、流程优化、风险防控、技能培训等方面的工作成果；同时直面当前细节管控精细化等方面的短板，并结合行业规范及医院发展实际，明确了2026年完善闭环管理、强化重点环节监管等关键改进举措。

院领导认真听取汇报后，对各委员会2025年的履职成效给予高度肯定，认为各委员会主动担当、扎实工作，有效筑牢了医院质量安全防线。针对2026年工作，院领导作出四点要求：一是提高政治站位，坚守质量安全底线，始终将患者安全放在工作首位；二是狠抓问题整改，对照短板建立“问题、责任、时限”三张清单，确保整改落地见效；三是强化协同联动，打破学科与部门壁垒，构建全方位质量安全管理体系；四是健全考核机制，将质量安全核心指标与绩效考核挂钩，推动管理工作常态化、规范化。

此次会议的召开，既系统复盘了过往工作，又精准定位了问题短板，进一步凝聚了全院质量安全工作共识，为2026年工作划定了路线图。下一步，徐州市妇幼保健院将以此次会议为契机，狠抓各项部署落实，持续提升医疗服务质量与安全水平，为广大妇女儿童提供更优质、安全、便捷的诊疗服务，夯实医院高质量发展根基。
