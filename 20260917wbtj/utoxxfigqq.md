# 吞咽造影检查为吞咽功能障碍患者带来福音

> 更新时间：2026-09-17 (UTC+8)

戳上面的蓝字关注我们哦！

**关注吞咽障碍患者**

畅享美味是人生中一件幸福的事，可是有的人却“谈吃色变”，对他们来说，吃却成了一种折磨和危险的尝试，他们就是**吞咽障碍患者**。

吞咽障碍会导致患者**误吸、吸入性肺炎、营养不良，甚至是窒息死亡**。

为开展好吞咽障碍的康复治疗，减轻吞咽障碍病人的痛苦， 6月16号，玉溪市人民医院康复医学科联合放射科**在地州级医院中率先开展吞咽造影检查**，为吞咽功能障碍患者带来了福音。

**案例**

患者普某某，2017年5月22日，因脑出血入院，严重的吞咽障碍让她不得不依靠鼻饲管来补充营养物质。

6月16日，在对该患者进行吞咽造影检查后，发现该患者舌根部运动不充分，咽肌无力，吞咽迟缓，在食用半流质食物时并无误吸和噎呛，可经口进食半流质食物。

通过吞咽造影检查，为该患者之后的吞咽功能训练和进食提供了依据，在检查后还成功拔出鼻饲管，并**顺利完成了经口进食**。

**吞咽造影检查（VFSS）**

也称为电视荧光放射吞咽功能检查，即在**透视下观察病人吞咽不同粘稠度、不同剂量的造影剂包裹的食团情况**，并通过从侧位及前后位成像对吞咽不同阶段的情况进行评估，也能对舌、软腭、咽喉的解剖结构和食团的运送过程进行观察。

吞咽造影检查操作简易，检查者能直观地实时观察患者的吞咽情况，是目前公认最全面、可靠、有价值的的吞咽功能检查方法。被认为是吞咽障碍检查的“理想方法”和诊断的“**金标准**”。

**吞咽造影检查的作用：**

1. 评估口腔结构、肌肉活动的协调性

2. 直观了解患者吞咽的不同阶段的情况

3. 明确是否存在误吸，误吸发生的时间、原因、量以及是否存在咳嗽反射

4. 为确定患者能否进口进食、食物粘稠度的选择提供可靠依据

5. 确定代偿方式

6. 为治疗决策提供依据，评定治疗效果

**吞咽造影检查的特点：**

1. 设备要求不高，简单易行

2. 能较敏感发现吞咽运动的细微异常改变

3. 能区分造成吞咽障碍的结构异常和功能异常

4. 真实反应是否有残留、误吸，以及清除吸入物的能力，吸入和吞咽的关系

5. 是吞咽障碍检查的“理想方法”和诊断的“金标准”

**吞咽造影检查的注意事项：**

1. 无吞咽动作或对钡剂**过敏**者禁止使用吞咽造影检查

2. 进食显影食物顺序和量需以安全为原则，每口的食物量一般从1ml起，**逐渐加量**，通常先液体，后糊状和固体，从一匙开始，如无问题逐渐加量

3. 注意**检查时间**，尽量减少X-射线照射

4. 检查前，对喂食者进行喂食**技巧指导**

5. 检查过程用固定带固定患者，以确保检查的**安全性**
